Drishti: fleet operations intelligence.

An operations console for state transport fleet management: live telemetry, demand forecasting, and risk scoring in one unified interface.

Discuss Vision Systems All Case Studies
01 // The Problem

Blind Spots in Transit Fleets

State transport operators struggled with disjointed telemetry: driver fatigue alarms, passenger overcrowding metrics, and route delays existed in isolated silos with zero real-time synthesis.

02 // The Architecture

Computer Vision + Fast API

Engineered on YOLOv8 edge models and FastAPI backends streaming frame inferences over WebSockets. Synthesizes real-time camera telemetry with predictive route risk models.

03 // The Impact

Sub-50ms Detection

Operational in testing with sub-50ms inference latency, automated anomaly alerts, and a streamlined operations dashboard displaying live fleet status on high-resolution screens.
