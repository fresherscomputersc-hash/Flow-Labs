Drishti: fleet operations intelligence

An operations console for state transport fleet management: live telemetry, demand forecasting, and risk scoring in one unified interface.

Status: built in-house, production system.

What it is

Drishti (which literally means “eyes”) is a fleet-operations intelligence console. It pulls live telemetry, forecasts demand and flags operational risk for a state transport corporation, so the morning meeting starts from one dashboard instead of five phone calls.

The problem

  • Fleet data lived in separate silos: GPS, depot reports, paper registers and one overloaded Excel.
  • Nobody could see the whole network in real time.
  • Forecasting demand was a person’s best guess, made every night.

How we approached it

We designed around the operator, not the data. The screen answers three questions in order: what is happening now, what will happen next, what needs a decision today. Live telemetry feeds the now. A demand forecasting layer feeds the next. Risk scoring surfaces the third, quietly.

Stack

  • Operational dashboard UI (real-time data views)
  • Forecasting layer for demand prediction
  • Risk scoring module
  • Python data stack behind the console
